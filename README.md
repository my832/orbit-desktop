# Orbit Desktop

Windows 10/11 x64 floating orb for quick app access and system controls. The installer and portable package are published in [Releases](https://github.com/my832/orbit-desktop/releases/latest); this repository includes the complete source archive.

## Build from source

Extract `Orbit-Desktop-1.0.0-source.zip` and follow its README. The project uses Electron and native Windows APIs; `npm ci` followed by `npm run dist` builds the installer and portable ZIP on Windows x64.
